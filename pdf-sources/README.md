# Sources

2025_hyperedge-percolation_2504.15213.pdf (text in the .txt file): Kovács, Benedek, Palla. Community detection in hypergraphs through hyperedge percolation. Scientific Reports 2025, arXiv:2504.15213. The paper extends clique percolation to hypergraphs with small-edge and large-edge variants and tests them on synthetic hypergraphs and real data; the package in `../hypernet` implements and evaluates that method.
